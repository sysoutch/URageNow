# Poker Blind Level Manager

![Thumbnail](thumbnail.png)

Manage blinds and levels for your home poker tournaments.

## Features
- **Timer**: Keep track of the current level duration.
- **Blind Structure**: Set small and big blinds for each level.
- **Alerts**: Audio notification when levels change.

## Usage
1. Configure your tournament structure.
2. Start the timer.
3. Play poker!
