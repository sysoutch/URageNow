# Kanban Board

![Thumbnail](thumbnail.png)

A simple, privacy-focused Kanban board for managing your tasks and projects.

## Features
- **Drag and Drop**: Easily move tasks between columns.
- **Customizable**: Add, rename, or remove columns.
- **Local Storage**: Your data is saved automatically in your browser.
- **Privacy**: No data is sent to any server.

## Usage
1. Add columns (e.g., Todo, Doing, Done).
2. Add cards for your tasks.
3. Drag cards to update their status.
