# Filer

Dashboard-themed project analytics and data browsing tool for reviewing structured project information in sortable tables and charts.

## Features

- Tailwind-based dashboard layout with theme overrides.
- Chart.js visualizations.
- Sortable table-style data views.
- Scrollable panels for larger datasets.

## Workflow

1. Open the tool from the dashboard tools workspace.
2. Review the high-level charts and summary sections.
3. Sort or scan the data table to inspect project entries.

## Notes

This tool currently loads as a standalone browser view and uses dashboard theme tokens when available.
