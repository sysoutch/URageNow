# SVG Editor

![Thumbnail](thumbnail.png)

A powerful browser-based SVG editor for creating and modifying vector graphics.

## Features
- **Vector Tools**: Draw paths, shapes, and lines.
- **Path Editing**: Modify existing paths and nodes.
- **Export**: Save your work as standard SVG files.
- **Layer Management**: Organize elements efficiently.

## Usage
1. Open the tool to start with a blank canvas or import an existing SVG.
2. Use the toolbar on the left to select drawing tools.
3. Adjust properties in the right sidebar.
4. Click "Export" to save your creation.
