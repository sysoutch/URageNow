# QR Code Creator

![Thumbnail](thumbnail.png)

This tool generates QR codes from text, URLs, or other data. It's useful for creating shareable links, contact information, or any data that can be encoded in a QR code.

## Features

- Generate QR codes from text or URLs
- Customize QR code size, foreground, finder-eye, background, and border colors
- Add an uploaded image or logo with size, X/Y position, and image-border controls
- Download QR codes as images
- Preview before downloading
- Responsive design for various screen sizes

## How to Use

1. Enter the text or URL you want to encode
2. Adjust size, color, and QR-border settings if desired
3. Optionally upload a logo, then tune its size, X/Y position, and border
4. Preview the QR code
5. Download the QR code as an image
6. Share the QR code with others

## Technical Details

- Uses QR code generation library
- Supports various QR code formats
- Downloadable as composed PNG images, including borders and uploaded logos
- Responsive design that works on mobile and desktop
- No server-side processing required
