# Wave Animation

![Thumbnail](thumbnail.png)

Create beautiful, animated wave effects for your web pages using CSS and JavaScript.

## Features
- **Customizable**: Adjust wave height, speed, color, and complexity.
- **Real-time Preview**: See changes instantly.
- **Code Generation**: Get the CSS and JS code ready to copy-paste.

## Usage
1. Use the controls to tweak the wave animation.
2. Observe the preview at the top.
3. Copy the generated code to your project.
