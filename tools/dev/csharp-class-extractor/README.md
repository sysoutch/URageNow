# C# Class Extractor

![Thumbnail](thumbnail.png)

A developer utility to extract C# classes, structs, and enums from a single script file into separate files.

## Features
- **Regex-based Extraction**: Identifies classes, structs, and enums automatically.
- **Zip Download**: Download all extracted files in a single ZIP archive.
- **Preview**: View extracted content before downloading.
- **Namespace Handling**: Preserves namespace encapsulation.

## Usage
1. Paste your C# code into the input area.
2. Click "Extract & Preview".
3. Review the identified files.
4. Click "Download All as .ZIP".
