## Description

Only the Chat composer has a slash-command palette (dashboard/chat/slashCommandController.js); there is no app-wide way to jump to a studio, tool, bot or overlay from the keyboard, and the icon-only phone rail has no tooltips (8 of the rail buttons carry a title). Add a command palette opened with Ctrl/Cmd+K and a "?" shortcut sheet: fuzzy search over studios, the 67 tools, bots, 3D suites, game engines and overlays (Settings, Resources, Skills, Console), recent media, and actions like "New chat" / "Toggle rail". Reuse the Tools search index. Add title + aria-label to every rail button and show the label as a tooltip in compact/phone modes.
